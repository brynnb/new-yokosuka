# Design and adaptations

These documents discuss intentional New Yokosuka adaptations and proposed
integration work. Their recommendations are not implementation status.
Where they describe an existing boundary, follow the linked implementation
guide and focused tests for the current contract.

- [Shenmue I narrative adaptation](shenmue1-narrative-adaptation.md): shared-world
  policy, personal story context, and intentional departures from the original.
- [Storyline gameplay integration](storyline-gameplay.md): the proposed ownership
  and verification needed for personal story scenes and consequential outcomes.

Keep temporary priorities, task checklists, and progress reports in ignored
`internal-docs/`. Durable design decisions should explain the tradeoff and link
to the implementation once adopted.
