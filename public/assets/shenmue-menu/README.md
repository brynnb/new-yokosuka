# Shenmue Dreamcast start-menu textures

These PNGs were decoded from the original texture layers embedded in:

`extracted_files/data/TITLE/MENU.SPR`

The Dreamcast textures are stored bottom-up, so the exported PNGs have been
flipped vertically for normal browser and image-editor use.

Key files:

- `background.png` — 1024×512 cloudy sky with the dragon/phoenix ornament
- `medallion-red.png` — 128×128 selected menu disc
- `medallion-purple.png` — 128×128 unselected menu disc
- `footer-panel.png` — 512×128 ornamental lower text panel
- `start-menu-heading.png` — 512×64 ornamental heading plaque
- `new-game.png`, `continue.png`, `load.png`, `option.png` — menu labels
- `button-a.png`, `button-b.png`, `dpad.png` — Dreamcast control icons

The remaining small textures retain shortened names derived from their
original eight-byte texture identifiers. They are Japanese prompt and state
variants used by the menu.
